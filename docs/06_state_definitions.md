# 상태 정의서 (State Definitions)

> 업로드된 상태 정의표를 전사하고, 기존 산출물의 식별자와 **명칭 매핑**을 확정한다.
> 상태 정의의 **정본**은 「차량 전체 상태천이 §3.1」. 본 문서는 전사·매핑용.

---

## 1. 상태 정의 (다이어그램 상태정의표 전사)

| ID | 상태명(정본) | 정의 |
| --- | --- | --- |
| **INIT** | Initialization | IG-ON 직후 부팅 자기진단 구간. S1 도 S6 도 아니며, 자기진단 통과 시 S1, 실패/시간초과 시 S6 으로 나간다 |
| **S0** | Sleep | IG-OFF. 상시전원 대상만 살아 있고 나머지는 무여자. 암전류 관리 구간 |
| **S1** | Manual | 운전자 탑승 수동 운전. 원격 액추에이터(제동·가속·조향)는 무여자 또는 백드라이브 허용. 예외 — 순정 레버 철거로 Chassis uC·변속기어릴레이는 **여자 유지**(§1.3) |
| **S2** | Remote-Armed | RS 인증 완료·액추에이터 여자 완료. 아직 원격 명령을 수용하지 않는 **대기** 상태 |
| **S3** | Remote-Active | 원격 명령 추종 중. 정상 원격 주행 상태 |
| **S4** | AEBS-Override | AEBS 가 제동을 강제 점유. 원격 제동·가속 명령보다 우선 |
| **S5** | Comm-Loss Brake | Heartbeat 타임아웃으로 통신 단절 판정. 비상 제동 유지 (임계값 SRS-SYS-007) |
| **S6** | Fault Safe State | 안전중요도 치명 등급 고장. 제동 유지 후 전 원격 입력 차단 (⚠️ "검출"→"확정" 수정 필요, 점검표 M02) |

---

## 2. 명칭 매핑 (정본 ↔ 기존 산출물) ★중요

> 업로드 다이어그램(정본 성격)과 기존 산출물(`01`~`03`, 스크립트)의 **상태명이 달랐다.**
> **다이어그램 명칭을 정본으로 채택**하고, 기존 산출물의 식별자는 아래 매핑으로 연결한다.
> (코드 식별자는 리팩터링 비용이 있어 유지하되, 주석/문서에 정본명을 병기)

| ID | 정본 명칭 (다이어그램) | 기존 산출물 식별자 | 비고 |
| --- | --- | --- | --- |
| S0 | Sleep / `SLEEP` | `SLEEP` | ✅ 일치 |
| INIT | Initialization / `INIT` | `INIT` | ✅ 일치 |
| S1 | Manual / `MANUAL` | `MANUAL` | ✅ 일치 |
| S2 | **Remote-Armed** | `REMOTE_READY` | ⚠️ 명칭 상이 — 의미 동일(원격 무장·대기). 정본=Remote-Armed |
| S3 | **Remote-Active** | `REMOTE_ACTIVE` | ✅ 사실상 일치 |
| S4 | **AEBS-Override** | `AEBS` | ⚠️ 정본=AEBS-Override (의미 동일) |
| S5 | **Comm-Loss Brake** | `SAFE_STOP` | ⚠️ 명칭 상이 — 의미 동일(통신두절 비상제동). 정본=Comm-Loss Brake |
| S6 | **Fault Safe State** | `FAULT_SAFE` | ✅ 사실상 일치 |

> **권고**: 코드 enum 식별자를 정본에 맞추려면 `REMOTE_READY→REMOTE_ARMED`,
> `SAFE_STOP→COMM_LOSS_BRAKE`, `AEBS→AEBS_OVERRIDE` 로 변경. 발행 코드값(0~6)은 불변이므로 안전.
> 변경 여부는 사용자 결정 사항(점검표 M-명칭).

## 3. 상태 성질 요약

| ID | 유·무인 | 가역성 | 재진입 경로 |
| --- | --- | --- | --- |
| S0 | — | — | S1 에서만 진입 |
| INIT | — | — | 부팅 시 |
| S1 | 유인 | — | S0/INIT/S2/S4 에서 |
| S2 | 무인 | 가역 | **유일한 원격 재진입 관문** |
| S3 | 무인 | 가역 | S2 경유만 |
| S4 | 무인 | 가역 | 해제 시 직전상태(S3→S2) |
| S5 | 무인 | 가역 | 복구+차속0 시 S2 |
| S6 | — | **비가역** | IG-OFF 재기동+DTC 클리어만 |
