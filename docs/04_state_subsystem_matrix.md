## 매트릭스에서 도출되는 데이터/설계 함의

1. **제동 중재 공통점 (S4·S5·S6)** — 세 상태 모두 "최대 제동"이며, S4는 "원격 명령과 **큰 값** 채택"이 명시됨.
   → `brake_req_src_state` 출력 + 외부 「제동 명령 중재」가 max 중재. (데이터 딕셔너리 출력 §3)

2. **S2 의 보수성** — 액추에이터는 여자하되 Brake=위치0 / Gear=명령거부 / Accel=0 / Steering=중립.
   즉 **"무장했지만 움직이지 않는"** 상태. 방수총 방향 조종만 허용(소방 특장).
   → S2→S3 전이 전까지 어떤 주행 명령도 반영 안 됨 (전이표 T07 가드와 일치).

3. **S1 Gear 예외** — 순정 레버 철거로 Chassis uC·변속기어릴레이는 **여자 유지**(§1.3).
   → 전이표 T06(S2→S1) "변속계통 여자 유지" 와 일치.

4. **✅ Q-76 (조향) 확정 (C06)** — S5·S6 Steering 은 **홀드하되 EPS 를 제어하지 않아 내력(조향 토크) 미발생**.
   즉 조향을 능동 고정하지 않고 자유 상태로 둠. (종전 "마지막 각 유지"=능동홀드 서술을 정정)
   통신두절/치명고장 시 조향을 고정할지, 어느 각으로 둘지 미확정. 안전상 중요 → 조기 확정 필요.

5. **⚠️ S3 Gear 차속0 조건** — 원격 기어 명령 추종이 "차속 0일 때만".
   → 주행 중 기어 변경 금지. 데이터 딕셔너리 §5.1 에 미해결로 등재(`TBD_STANDSTILL_SPEED` 연계).

## 상태 ↔ FSM(소방특장) 요약

| 상태 | FSM 동작 | 비고 |
| --- | --- | --- |
| S0 | OFF | |
| S1 | 운전자 조작 가능 | |
| S2 | 대기 + 방수총 방향 조종 | 주행은 불가, 상부 조작만 |
| S3 | 원격 명령 추종 | |
| S4/S5 | 영향 없음 | 섀시 안전개입이 상부와 독립 |
| S6 | 정지 | |

> FSM(소방특장)은 §2 "`FSM uC` 가 `S6` 항목만 관리"와 연계 — S6 발행 시 FSM 측도 정지.
