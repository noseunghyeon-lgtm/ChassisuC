# 원격 차량 제어 Top StateMachine — 전이표 (State Transition Table)

> 본 전이표는 설계 문서 「전체 관리 프로세스 / 1 — 상태 머신」의 구현 설계다.
> 상태 정의·명칭·천이 조건의 **정본**은 「차량 전체 상태천이 §3」이며, 본 표는 그 정본을
> SW로 구현하기 위한 **평가 순서·진입/이탈 액션·금지 천이 감시**를 담는다.
> 정본에 없는 임계값/정책은 절대 임의로 채우지 않고 `[TBD]` + 소관 SRS ID로 표기한다.

## 1. 평가 순서 · 우선순위 (문서 §3)

한 틱(10ms)에서 여러 천이 요구가 동시 성립할 때 **발행 상태를 정하는** 단일 순서.

| 순위 | 조건 | 결과 상태 | 비고 |
| --- | --- | --- | --- |
| **0** | E-Stop 작동 | `[TBD]` | 「안전」 소관. 미정의 (§10) — 자리만 확보 |
| **1** | 안전중요도 **치명** 고장 **확정** | `S6` | 확정 신호 수신 시. 디바운스는 「진단」 §4 소관 |
| **2** | Heartbeat 미수신 (`S2`·`S3`에서만) | `S5` | 임계값 400ms (SRS-SYS-007) |
| **3** | AEBS 제동 판정 | `S4` | TTC < 0.8s (SRS-SYS-003) |
| **4** | 모드 전환 요청 | `S1`↔`S2`↔`S3` | 「원격/수동 전환」 소관 |

**중재 규칙:**
- `S4`·`S5`는 배타 아님. 동시 성립 시 **발행 상태는 우선순위 높은 쪽**(S5>S4는 아님 — 순위표상 S5=순위2 > S4=순위3이므로 **S5 발행**), 단 **제동 요구는 두 요구원의 최댓값**(「제동 명령 중재」 소관).
- 동시 성립 시 **동시성립 플래그를 별도 비트**로 발행 → `VEH_STS` 바이트 배정 확정 시 반영 (§10, `[TBD]`).
- 해제는 **두 조건이 모두 해소될 때만**.

## 2. 전이표 (Event / Guard / Action)

표기: `Guard`=천이 허용 조건, `Entry/Exit Action`=진입·이탈 시 수행. `[TBD]`는 미확정.

### 2.1 부팅 / 전원 계열

| # | From | To | Trigger / Guard | Action 순서 | 실패 시 |
| --- | --- | --- | --- | --- | --- |
| T01 | `S0` | `INIT` | Wakeup (IG-ON / Wake source) | 부팅, 상태변수=INIT | — |
| T02 | `INIT` | `S1` | 자기진단 완료 && 기어계통 준비완료 | §12-1 시퀀스(1~9) | **[TBD]** 원문 실패처리 없음 (§12-3) — `S6` or 대기? 사용자 확정 |
| T03 | `INIT` | `S6` | 자기진단 중 치명 고장 확정 | → S6 진입 시퀀스 | — |
| T04 | `S1` | `S0` | IG-OFF | §12-2 시퀀스(1~5): 하위계통 정리 후 Chassis uC 마지막 슬립 | **[TBD]** 원문 실패처리 없음 (§12-3) |

> `S0` 진입은 **`S1`에서만** 허용 (§6-5). `S2`·`S3`에서 IG-OFF → 먼저 `S2→S1` 강제 후 `S0`.
> `S6`에서 IG-OFF는 허용 (정본이 재기동을 S6 이탈 수단으로 규정).

### 2.2 유인 ↔ 원격 계열 (§4)

| # | From | To | Trigger / Guard | Action 순서 | 실패 시 |
| --- | --- | --- | --- | --- | --- |
| T05 | `S1` | `S2` | 인터록 4조건 충족 && 모드전환 요청 | ① 인터록 4조건 확인 → ② 제동 액추에이터 여자 + **현재 페달 위치에 캠 정합** 후 위치0 유지 → ③ 조향 중립 확인 → ④ 가속 0 고정 → ⑤ 전 모듈 준비완료 보고 → `S2` 발행 | 어느 단계든 실패 시 `S1` 복귀 + 사유코드. **부분 여자 상태 금지** |
| T06 | `S2` | `S1` | 모드전환 요청 (원격 해제) | ① 제동 유지 → ② 액추에이터 순차 무여자(**제동은 캠 원점 복귀 후** 무여자) → ③ 변속계통 **여자 유지**(정본 §3.1 예외) → ④ `S1` 발행 | 캠 원점 복귀 실패 시 **무여자 금지 + 고장 보고** |
| T07 | `S2` | `S3` | 전 조작기 중립 확인 && 첫 유효명령 수신 | ① 중립 확인 → ② 첫 유효명령 수신 → ③ 명령 추종 개시 | 중립 미확인 시 **천이 금지** (정본 §3.3) |
| T08 | `S3` | `S2` | 원격 세션 종료 / 정지 요청 | ① 원격명령 중립 램프다운 → ② 차속 0 확인 → ③ 명령 수용 중단 | 차속 0 미달 시 감속완료까지 `S3` 유지 |

## 3. 금지 천이 감시 (§7)

| 금지 천이 | 감시/대응 |
| --- | --- |
| `S3 → S1` 직접 | 천이 함수에서 **원천 차단**. 시도 발생 시 **SW 결함 → DTC 발행** |
| `S5 → S3` 직접 | 원천 차단. 반드시 `S2` 경유 (정본 §3.3 · SRS-SYS-023) |
| `S6`에서 원격 이탈 | 원천 차단. 원격으로 이탈 불가 |
| 정의되지 않은 상태값 | 열거 범위 이탈 시 **즉시 `S6`** (상태 머신 손상 간주) |

## 4. 상태 머신 자기진단 (§8)

| 항목 | 규칙 |
| --- | --- |
| 틱 지연 감시 | 10ms 주기 규정 초과 지연 시 결함 계상 (SRS-SYS-038) |
| 상태 변수 무결성 | 열거 범위 검사 + **이중화 저장(정·역 보수)** 비교 |
| 천이 이력 로깅 | 직전 N개 천이(시각·사유·요청원) 보관 (SRS-SYS-040) |
| 워치독 | 태스크 정지 시 HW 워치독 리셋. **리셋 후 `INIT`부터 재시작 — `S3` 자동 복귀 금지** |
